# Contributing

**statica** is developed in the [GitHub repository](https://github.com/gtriggiano/statica): bug reports, documentation fixes and code changes go there, as issues and pull requests.

- **Bug reports.** Include the output of `statica version`, the relevant part of the configuration and the log lines. Remove credentials, bucket names and hostnames you do not want to publish.
- **Documentation.** Each page links to its source with "Edit this page on GitHub". A statement about behavior must match the code.
- **Code.** Include tests for the behavior you change, and update the documentation in the same pull request.
- **Pull request titles.** Pull requests are squash-merged, and the title decides the next version and the changelog entry. It follows [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/), such as `fix(cache): count revalidated entries once`.

[CONTRIBUTING.md](https://github.com/gtriggiano/statica/blob/main/CONTRIBUTING.md) is the full guide: the requirements, the commands that check a change, a map of the code, the design rules, and the documentation and pull request conventions.
